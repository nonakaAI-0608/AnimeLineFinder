Anime Line Finder — Qwen3-ASR エンジン追加（2026-11-10）
===================================================
■使い方
1. 設定タブの「文字起こしエンジン」で「Qwen3-ASR ＋ ForcedAligner」を選びます。
2. 「Qwen3-ASR実行環境を導入（初回のみ）」を押します（Anime Whisperとは別の環境。既存環境は変更しません）。
3. 認識モデルを選び、「設定を保存」→ 動画タブで文字起こしします。
   ・アニメ・ギャルゲー追加学習版（初期値）：jaykwok/Qwen3-ASR-1.7B-JA-Anime-Galgame
   ・公式ベース版：Qwen/Qwen3-ASR-1.7B
   初回は合計約5GB（認識1.7B＋時刻合わせ0.6B）を自動ダウンロードします。
■違い
・字幕の時刻は Qwen3-ForcedAligner が音声から推定します。長いセリフを分割した位置の時刻も音声に基づきます。
・字幕の文字数/秒数の設定は共通です。
・2026-11-15修正：Qwen3-ASRでは、VADが「音声なし」とした2秒以上の区間も25秒以内に分けて認識します。
  BGMと重なったセリフをVADがほぼ検出できず、約1分半の会話がまるごと抜けていたためです
  （テスト動画で 405行→569行、約1分半の会話が復活）。
  Qwen3-ASRは本当の無音では文字を出さないため、漏れを防ぐ代わりに処理時間が少し増えます（第1話で約7分）。
  「…」「♪」など文字を含まない結果は字幕にしません。
・2026-11-17修正：Qwen3-ASRで、OP・EDなどの歌を字幕にしないようにしました（設定の「OP・EDなどの歌を字幕にしない」、初期値ON）。
  音声分類モデル（AST／AudioSet、約350MB・初回のみダウンロード）で「話し声が少なく、歌声のある音楽が30秒以上続く区間」を判定します。
  BGMと重なったセリフは話し声として判定されるため除外されません。30秒以上の劇中歌も歌として除外されます。
  テスト動画4話分でOP・EDを判定できることを確認済み。判定区間は文字起こしのログに表示されます。
  既に作成済みのSRTは、もう一度文字起こしすると反映されます。
・繰り返し抑制（no_repeat_ngram）の設定はAnime Whisper専用です。反復の疑いはログと検索画面の⚠で確認できます。
・どちらが高精度かは作品・音源で変わります。同じ動画を両エンジンで再文字起こしして比べてください。

Anime Line Finder v1.6 — 無発話区間の誤生成対策（Silero VAD）
===================================================

■ v1.6の使い方（v1.5から上書き更新する場合）
1. ツールを終了し、最新版ZIPを展開して中身を既存フォルダに上書きしてください。
2. 設定タブで「VADだけ追加導入」を押し、完了まで待ちます。
   ※ 既存Anime Whisperのモデル（約3GB）やGPU環境を入れ直す必要はありません。
3. 動画・文字起こしタブの「無発話区間を除外（Silero VAD）」をONにしてください。
   初期設定はON、しきい値0.35です。
4. 「選択動画を再文字起こし」から対象動画を選んで実行します。
   v1.5以前に作ったSRTは自動更新されないため、再文字起こしが必要です。
   更新前のSRTは初回の上書き時に *.srt.before_vad.bak に保存します。

■ VAD感度
0.25：検出を緩くする（小声・叫び・ささやきの取りこぼしが心配な場合）
0.35：初期値（比較的広く声を拾う）
0.45 / 0.55：厳しめ（BGM等の誤生成が残る場合）
0.65：さらに厳しくする（実際のセリフを取りこぼす可能性が上がります）
しきい値が小さいほど、発話と判定される区間が増えます。

■ 動作の考え方
・まず録画音声（16kHz、モノラル）からSilero VADで発話の候補区間を検出。
・検出した区間だけをAnime Whisperに入力します。BGMは除去しません。
・短い発話区間は適度にまとめますが、長い無発話部分は入力しません。
・SRTの時刻は元の動画のタイムラインのまま保存します。
・無発話の区間をVADが取りこぼす/誤検出することはあります。
・「無発話区間を除外」をOFFにすればv1.5相当の認識方式になります。
・BGMだけの場所でもVADが誤検出する場合はあります。
・感度を厳しくしすぎるとアニメ特有の小声、吐息、笑い声などが落ちる恐れがあります。

■ 注意
・初回のVAD追加導入時のみインターネット接続が必要です。
・追加導入先は既存の%LOCALAPPDATA%\AnimeLineFinder\.venv_animewhisperです。
・CUDAを含む既存PyTorchとAnime Whisperモデルはそのまま利用します。
・新方式では認識する音声区間が変わるため、セリフの時刻が変わることがあります。
・VADは音源の分離ではなく、発話らしい場所を検出するものです。
・実際のWindows環境でのSilero VAD + Anime Whisper同時推論は未検証です。

Anime Line Finder v1.5 — 再生位置補正・繰り返し誤認識対策版
======================================================

■ v1.5で追加したこと（2026-11-08）
【1】セリフごとの再生時刻補正
「セリフ検索」で行を選択し、下の「0.5秒早く」「0.5秒遅く」で
再生開始位置を調整してください。調整値は作品データ内に自動保存されます。
行をダブルクリック、または「該当場面を再生」で確認します。
「補正をリセット」でその行だけ補正を取り消します。
正の補正は再生を後ろへ、負の補正は再生を前へずらします。
初期の「再生前の余裕」を1.5秒から0.5秒に変更しました。
この余裕は全行共通で0～5秒に変更でき、次回起動にも保存されます。
【注意】再生補正はSRT自体を書き換えません。字幕の開始時刻は
Anime Whisperの推定値で、文章を文字数で分割した箇所は精密ではありません。
SRTを書き直した行では以前の補正が引き継がれない場合があります。

【2】Anime Whisper の繰り返しハルシネーション対策
開発者が推奨する no_repeat_ngram_size=5 を初期値にしました。
「動画・文字起こし」で 5 / 10 / 0 を変更可能です。
5=標準（推奨）、10=弱め、0=無効。設定は次回の認識に適用します。
明らかな文字・音節の連続を検出した区間は、さらに厳しい設定で
1回だけ再認識し、改善した場合はその結果を採用します。
改善しない場合は元の字幕を保持します（勝手に消しません）。
検索画面で「⚠」が付いた行は自動判定で「要確認」の候補です。
「疑わしい字幕を隠す」にチェックすると一覧だけから隠します。
SRTファイルは削除・変更しません。正しい反復セリフを警告する
可能性もあるため、実際の音声と聴き比べてください。
※既に保存されたSRTへ認識精度改善を反映するには、動画・文字起こしの
  「選択動画を再文字起こし」から再実行が必要です。
※BGM中の誤認識や存在しない台詞の生成を完全に防ぐものではありません。
※モデル・GPU用環境はそのまま再利用でき、再導入は不要です。

■ v1.4で修正したこと（2026-11-08）
・公式 Anime Whisper モデルで文字起こし開始直後に
  IndexError: list index out of range
  が出る問題を修正しました。
・原因：モデルのデコーダーは2層ですが、付属 generation_config の
  alignment_heads は7～25層を参照しており、Transformersの
  return_timestamps="word" が動作しません。
・修正：起動時にalignment_headsを検証し、対応しない場合は
  return_timestamps=True （通常の字幕区間時刻）へ切り替えます。
  長い字幕は従来と同様に句読点・文字数・秒数で短く分割しますが、
  分割後の時刻は文字数に基づく推定であり、単語ごとの正確な位置ではありません。
・例外時にも通常時刻で再試行する処理を追加しました。
・手動でPyTorch/モデルを再インストールする必要はありません。
・モデル1話分の実GPU推論は未検証のため、まず第1話で試してください。

■ v1.3で追加・修正したこと
1. MPC-HC / MPC-BE に対応しました（64bit版も可）。
   「設定」→「動画プレーヤー」に mpc-hc64.exe / mpc-be64.exe 等を指定してください。
   空欄での自動検出も、K-Lite Codec Packなどの標準インストール先を探します。
   検索結果をダブルクリックすると、字幕の開始時刻より0.5秒前から再生します（v1.5で変更）。
   MPCの /start ミリ秒 /play オプションを利用しています。

2. 「セリフ検索」の検索欄が空なら、登録した動画の全セリフを表示します。
   名前・文を入力すると絞り込み、検索欄を消すと全件表示に戻ります。
   未文字起こしの話数はセリフがないため表示されません。

3. 1セリフ（SRTの1行）の区切りを短くしました。
   「動画・文字起こし」タブに「最大文字数」「最大秒数」を追加。
   初期値は24文字／4.0秒です。任意に変更して文字起こしできます。
   Anime Whisperでは利用可能な時刻方式を先に確認します。
   この公式モデルは単語時刻の設定に不整合があるため通常の区間時刻を
   利用し、長い字幕は文字数や句読点に基づき時刻を推定して分割します。

4. 既に生成済みのSRTを再文字起こしなしで区切り直せます。
   「動画・文字起こし」→処理する動画を選択→
   「既存SRTの区切りを短くする」を押してください。
   動画未選択の場合は確認のうえ、この作品の全SRTを対象とします。
   変更前のSRTは .srt.before_split.bak に保存されます（初回のみ）。
   注意：既存SRTの短縮では単語の正確な時刻が無いため、分割時刻は
   文字数に基づく推定です。正確な切れ目が必要なら再文字起こしを
   お試しください。ただし今回のAnime Whisperでは再文字起こししても
   単語単位の正確な時刻は得られません。

5. v1.2から作品データ・辞書・生成SRT・モデルキャッシュを引き継ぎます。
   モデルは既存のキャッシュを再利用します。全話の再文字起こしは不要です。
   専用Python環境は次の順に再利用します：
   ・同じフォルダの .venv_animewhisper
   ・%LOCALAPPDATA%\AnimeLineFinder\.venv_animewhisper
   見つからなければ「設定」から導入してください。新規導入はデータフォルダに保存します。

■ v1.2で追加したこと
「litagin/anime-whisper」を、Subtitle Editを通さず直接使えます。
公式モデル（model.safetensors 約3.03GB）を自動ダウンロードする方式で、
Faster Whisper用にCTranslate2変換する必要はありません。

初回の必要なセットアップ（Windows 10/11 x64想定）
1. ZIPを展開（旧v1.1とは別フォルダがおすすめ）。
2. 「起動.bat」を実行（Python 3.10以降が必要）。
3. 「設定」タブで「Anime Whisper（公式モデル・直接利用）」を選択。
4. 「Anime Whisper実行環境を導入（初回のみ）」を押します。
   → 導入画面が開き、GPU用PyTorch・Transformersなどをインストール。
   → 原則としてPython 3.10・3.11・3.12 x64のいずれかが必要です。
   → Python 3.11が推奨です。導入画面の最後に CUDA: True が出るとGPU認識OK。
   → 導入失敗時は同じボタンから再試行できます。
5. 「導入状態を確認」でPyTorchとCUDAの状態を確認。
6. 「動画・文字起こし」でMKV/MP4を追加し、「未処理の動画を文字起こし」。
   → 初回は公式モデルを約3GBダウンロードして、ローカル保存します。
   → 2回目以降は同じモデルを再利用し、Google Driveは不要。
   → 音楽/BGMの除去は不要です。音声の種類によって精度は変わります。
7. 完了した字幕はSRTとして保存され、「セリフ検索」で全話横断検索可能。

モデルの保存場所：
  %LOCALAPPDATA%\AnimeLineFinder\models\huggingface
※ HF_HOMEは上記に設定され、モデル本体はその配下のhubに保存されます。
※ 公式モデルファイル「model.safetensors」は単独で配置しなくてもOK。
※ 初回はモデル約3GBに加え、専用PyTorch環境の容量も必要です。
※ GPUはCUDA対応のNVIDIA GPUを使用します。CUDAが利用できない場合はCPUで処理。
※ RTX 2070 SUPERを想定し、GPUメモリを節約するためバッチサイズは1です。
※ モデルは各ファイルを処理する際に読み込み直すので、複数話でも
   初回のモデルダウンロード自体は一度だけですが、ロード時間は各話で発生します。

■ 登場人物・固有名詞辞書について（重要な変更）
モデル公開者はAnime Whisperにinitial_promptを使用しないように注意しています。
したがって【公式Anime Whisperモードでは、固有名詞辞書を認識ヒントとして送信しません】。
登録した名前・読み・別名は、従来どおりセリフ検索時の表記揺れ吸収に使います。
例：辞書の「花小泉杏」には「はなこ」等の別名を登録できます。
「Purfview」モードに切り替えた場合は、従来どおり認識ヒントにも使用します。

Wikipedia・Annict取得、候補選択、一括登録、重複チェックも引き継いでいます。
Annict APIを利用する場合は読み取り専用の個人用トークンを入力してください。
トークンは設定には保存されません。

■ v1.1のデータ引継ぎ
設定と作品・字幕ファイルは以下に保存されているため、以前のZIPの
フォルダを削除しても（このデータフォルダを削除しない限り）引き継がれます。
  %LOCALAPPDATA%\AnimeLineFinder\

v1.2はエンジンの標準値を公式Anime Whisperへ切り替えます。
Purfviewを今までどおり使いたい場合は「設定」から切り替えてください。

■ 既存機能
・MKV/MP4/AVI/TSなど、動画の複数登録・フォルダ再帰検索
・BGMを除去せず文字起こし、SRTを作品別に保存
・処理済みSRTのスキップ、選択動画の再文字起こし、進捗・キャンセル
・同名のASSは文字起こしに混ぜません

・既存SRT取込、CSVエクスポート

■ 注意点と制限
・インストール時とモデル初回取得時のみインターネット接続が必要。
・実行環境の導入には数GBの通信量と空きディスク容量が必要です。
・モデルによる時刻推定は数秒程度ずれる可能性があります。
・人名やセリフの認識精度は保証されません。
・モデルが時間情報を返さない区間はおおよその時刻でSRT化します。
・キャンセル時は未完了ファイルのSRTを採用せず、完成済みのSRTは残ります。
・Windows実機でのGPU・GUI・Hugging Faceモデル実行の動作確認は未実施。
  模擬音声認識による処理とSRT検索のテストのみ実施しています。

■ EXE作成
「EXE作成.bat」でGUIのEXEを作れます。専用Anime Whisper環境は外部に置き、
EXEへ巨大なGPU関連ライブラリは埋め込みません。
EXEを使う場合は dist\AnimeLineFinder フォルダ全体を保持してください。
EXE側の「Anime Whisper実行環境を導入」を押すと、そのフォルダに環境を作成します。
